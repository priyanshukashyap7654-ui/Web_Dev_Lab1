# Program 2: Repository and Initial Commit

## Objective
To create a portfolio project and initialize a Git repository with an initial commit.

## Commands Used
* `git init` - Initializes a new Git repository.
* `git status` - Checks the status of the working directory and staging area.
* `git add .` - Stages changes for commit.
* `git commit -m "Initial commit"` - Records changes to the repository.
