# Program 1: Project Folder and Terminal Navigation

## Objective
To create a project folder and understand basic terminal navigation commands[cite: 27].

## Commands Used
* `pwd` - Prints the current working directory[cite: 27].
* `ls` - Lists files and folders in the current directory[cite: 27].
* `mkdir` - Creates a new directory[cite: 27].
* `cd` - Changes the current working directory[cite: 27].
