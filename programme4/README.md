# Program 4: GitHub README and Version Tags

## Objective
To document the repository via README files and create annotated version tags for release.

## Commands Used
* `git tag -a v1.0.0 -m "Release version"` - Creates an annotated version tag.
* `git push origin v1.0.0` - Pushes version tags to GitHub.
* `git push origin main` - Pushes main branch updates to GitHub.
